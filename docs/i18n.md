# Wersje językowe

Języki: **polski (źródło, domyślny), niemiecki, ukraiński, hiszpański**.
Adresy się nie zmieniają — język siedzi w ciasteczku `vairo-locale`
i w `profiles.locale` (migracja 049).

## Jak wybierany jest język

1. Zalogowana osoba: `profiles.locale` (Ustawienia → Konto → Język).
   `LocaleSync` w layoucie `/app` wyrównuje ciasteczko z profilem.
2. Ciasteczko `vairo-locale` — ustawia je `src/proxy.ts` przy pierwszym
   wejściu na podstawie `Accept-Language`, potem przełącznik języka.
3. Nic nie pasuje → polski.

## Dwa rodzaje tekstu, dwa miejsca

| Co | Gdzie | Narzędzie |
|---|---|---|
| Interfejs: przyciski, komunikaty, błędy, powiadomienia | `src/i18n/messages/<język>/<przestrzeń>.json` | `npm run i18n:check`, `npm run i18n:sync` |
| Treść etapów: pytania, podpowiedzi, przykłady, przewodniki | `supabase/content/i18n/<język>/<etap>-v1.json` | `node scripts/content-i18n.mjs extract|check|build` |

Brak tłumaczenia nigdy nie daje pustego ekranu: interfejs bierze tekst
z `pl`, a treść etapu polski wiersz z bazy.

## Interfejs

- Komponent serwerowy: `const t = await getT("social")`.
  Kliencki: `const t = useT("social")`. Akcja serwerowa:
  `(await getT("team"))("errors.lastFounder")`.
- Klucze są typowane z polskich plików JSON — literówka w kluczu to błąd
  `tsc`. Zmienne: `{name}`, liczby: `{count, plural, one {…} few {…} other {…}}`
  (polski i ukraiński mają `few`/`many`, niemiecki i hiszpański tylko
  `one`/`other`).
- Daty: `LOCALE_TAGS[locale]` z `src/i18n/config.ts`, nigdy `"pl-PL"`
  na sztywno. W celach i plikach gotowe formatery: `useGoalFormat()` /
  `useDateFormat()` (klient), `makeGoalFormat(t, locale)` /
  `makeDateFormat(locale)` (serwer).
- Bezosobowo jak dotąd — reguła z CLAUDE.md obowiązuje też w DE/UK/ES
  (w ukraińskim unikamy form rodzajowych czasu przeszłego).
- **Celowo po polsku:** instrukcje mentora AI (`src/lib/ai/prompts.ts`,
  kontekst w `src/app/api/ai/assist/route.ts` — model dostaje osobną
  instrukcję, w jakim języku odpowiadać) i mail do skrzynki zespołu
  w Pomocy (`help/actions.ts`, czyta go zespół Vairo).

### Nowy tekst w interfejsie

1. Dopisz klucz do `src/i18n/messages/pl/<przestrzeń>.json` i użyj go w kodzie.
2. Dopisz ten sam klucz w `de`, `uk`, `es`.
3. `npm run i18n:index` (tylko przy nowej przestrzeni), potem `npm run i18n:check`.
4. `npm run i18n:sync`.

### Zmiana istniejącego polskiego tekstu

`npm run i18n:check` wypisze klucz w sekcji „Zmieniony polski tekst”.
Popraw ten klucz w `de`/`uk`/`es`, potem `npm run i18n:sync`. **Nic więcej
nie trzeba tłumaczyć.**

## Treść etapów

Polski JSON w `supabase/content/*.json` jest jedynym źródłem struktury.
Tłumaczenie to płaska mapa „ścieżka → tekst”; ścieżka składa się z kluczy
(`kategoria/punkt/podpunkt/pole.question`), nie z pozycji.

### Po zmianie treści etapu

```bash
npm run content:build -- <plik>                 # jak dotąd: nowa migracja treści
node scripts/content-i18n.mjs extract <etap>    # odświeża polskie źródło i skróty
node scripts/content-i18n.mjs check             # co jest nowe albo nieaktualne
```

`check` pokazuje dla każdego języka tylko **brakujące** (nowe pole) i
**nieaktualne** (zmienione polskie zdanie) ścieżki. Tłumaczy się tylko je —
reszta zostaje. Potem:

```bash
node scripts/content-i18n.mjs build 051         # kolejny wolny numer
```

`build` składa komplet tłumaczeń w jedną idempotentną migrację. Odpalonego
pliku się nie edytuje — każda nowa wersja dostaje nowy numer, obowiązuje
najwyższa.

## Baza

- `049_i18n` — `profiles.locale` (pl/de/uk/es) i `translations jsonb` w
  `stage_templates`, `stage_categories`, `stage_points`, `stage_subpoints`,
  `stage_fields`.
- `050_content_translations` — tłumaczenia treści etapów (generowane).
- Kod działa też bez 049: zapytania z `translations` mają ścieżkę zapasową
  (`isMissingTranslations` w `src/lib/stage-i18n.ts`).

## Maile z Supabase

Link logowania wysyła `data: { locale }` do `user_metadata`. Szablony maili
w Supabase (Authentication → Email Templates) mogą rozgałęzić treść:
`{{ if eq .Data.locale "de" }}…{{ else }}…{{ end }}`. Bez tego maile zostają
po polsku.
